Progetto di Programmazione Avanzata di Spicuzza Marco Pio.

È necessario richiedere una key API da TMDB da inserire in "...\server\src\main\resources\config.properties".

Applicazione distribuita Java basata su architettura Client-Server. Include un client desktop con interfaccia grafica interattiva e un backend di servizio che espone API HTTP (con scambio dati in formato JSON/XML) per la gestione e la persistenza dei dati su database MySQL. I progetti lato client e lato server sono strutturati separatamente per garantire la massima modularità.
